# 📘 السؤال الثاني عشر - إدارة بيانات الأجهزة الإلكترونية

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يستخدم `struct` لإدارة أجهزة في متجر (الاسم، الشركة، السعر، الكمية). لكن الجديد هنا هو برمجة **دوال إدخال وعرض داخل الـ Struct نفسه!**
كما يتحقق البرنامج من صحة السعر والكمية (يجب أن يكونا أكبر من 0).

---

## 📚 ما الجديد في هذا البرنامج؟

### 1- الدوال (Functions) داخل الـ Struct
في C++، يمكننا كتابة دوال داخل الـ struct نفسه (وهذه بداية لمفهوم البرمجة الكائنية OOP - Classes).

```cpp
struct Device {
    string name;
    double price;

    // دالة داخلية للإدخال!
    void inputData() {
        cout << "أدخل الاسم: ";
        getline(cin, name); // الـ name المعرف في الأعلى
    }
};
```
ميزتها؟ تجعل الكود أنظف! نستدعيها هكذا: `devices[i].inputData();`

### 2- التحقق من البيانات أثناء الإدخال (Data Validation)
نستخدم حلقة `do-while` لإجبار المستخدم على إدخال قيم صحيحة:

```cpp
do {
    cout << "السعر: ";
    cin >> price;
    if (price <= 0) cout << "خطأ! السعر يجب أن يكون > 0";
} while (price <= 0); // كرر الطلب طالما السعر غير صحيح
```

### 3- تنسيق المخرجات باستخدام `<iomanip>`
لكي يظهر الجدول مرتبًا وبأعمدة محاذية، نستخدم أداة `setw` (تحديد عرض مساحة العرض) و`left` أو `right` لمحاذاة النص.

- يجب تضمين المكتبة: `#include <iomanip>`
- الاستخدام: `cout << setw(20) << left << name;` يطبع الاسم ويحجز له 20 مسافة على الشاشة ويحاذيه لليسار.
