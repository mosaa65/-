# 📘 السؤال الرابع عشر - المشروع الشامل (نظام مطعم)

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 فكرة المشروع

هذا هو **المشروع النهائي** الذي يجمع كل ما تعلمناه في المادة في برنامج واحد واقعي وعملي.
اخترت برمجة **"نظام إدارة طلبات مطعم"**.

يحتوي البرنامج على:
1. **Structs (السجلات):** لتخزين بيانات الأصناف، الطلبات، والفاتورة.
2. **Arrays (المصفوفات):** قائمة الطعام هي مصفوفة، والطلبات في الفاتورة مصفوفة أيضاً.
3. **Functions (الدوال):** تم تقسيم البرنامج إلى دوال صغيرة (مثل دالة عرض القائمة، دالة أخذ الطلب، دالة طباعة الفاتورة).

---

## 📚 كيف تم تطبيق الدروس في هذا المشروع؟

### 1- استخدام الـ Structs (لترتيب البيانات)
تخيل لو أردنا حفظ معلومات 6 أصناف في المطعم.. سنحتاج 6 متغيرات للاسم، 6 للسعر، 6 لرقم الصنف! هذا متعب جداً.
الحل؟ `Struct` يجمع كل هذا:

```cpp
struct MenuItem {
    int id;           // رقم الصنف (مثلاً 101)
    string name;      // اسم الصنف (مثلاً برجر)
    double price;     // السعر (25.5)
    bool available;   // متوفر للبيع أم نفذت الكمية؟
};
```

وثم نستخدم مصفوفة تضم كل الأصناف هكذا: `MenuItem menu[6];`

### 2- استخدام Functions (لترتيب الكود)

بدلاً من كتابة كل شيء في `main` وجعل الكود طويلاً ومخيفاً، قسّمناه لدوال:
- `displayMenu` : وظيفتها فقط طباعة قائمة الطعام.
- `takeOrder` : وظيفتها فقط التفاعل مع الزبون وأخذ طلبه.
- `printBill` : وظيفتها فقط طباعة الفاتورة النهائية وحساب الضريبة.

هذا يجعل الكود **سهل القراءة** و **سهل التعديل**.

### 3- استخدام Pass by Reference `&`

في دالة `takeOrder` أردنا أن نعدل على الفاتورة `currentBill` ونضيف لها طلبات. لو مررناها عادياً سيقوم البرنامج بعمل "نسخة" وتعديلها دون المساس بالأصل!
لذلك استخدمنا علامة `&`:

```cpp
void takeOrder(..., Bill &currentBill)
```
علامة `&` تقول للبرنامج: خذ الفاتورة الأصلية وعدّل عليها مباشرة.

## 🔄 كيف يعمل البرنامج من الداخل؟ (شرح مبسط للمبتدئين)

1. أول ما يشتغل البرنامج، يمر على دالة `setupMenu` ليعبئ المصفوفة بأسماء الوجبات وأسعارها.
2. يظهر **قائمة (Menu)** رئيسية للمستخدم فيها 4 خيارات وتسأله: ماذا تريد أن تفعل؟ `cin >> choice`
3. قمنا باستخدام `Switch` لتوجيه المستخدم بناءً على رقمه:
   - لو اختار 1: نستدعي دالة طباعة الأكل.
   - لو اختار 2: نجهز فاتورة جديدة ونستدعي دالة أخذ الطلبات.
   - لو اختار 3: نستدعي دالة طباعة الفاتورة.
   - لو اختار 4: نودعه ونخرج من البرنامج.
4. هذا كله موضوع داخل حلقة `do-while(choice != 4)` لكي يظل البرنامج شغالاً حتى يقرر المستخدم الخروج.
