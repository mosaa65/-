# 📘 السؤال الثالث - إدخال مصفوفة وإضافة عنصرين جديدين

**اسم الطالب:** عمار الحميري  
**اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

1. يطلب منك إدخال عدد من الأرقام في مصفوفة
2. يعرض المصفوفة كما هي
3. يطلب منك عنصرين جديدين ويضيفهما في النهاية
4. يعرض المصفوفة بعد الإضافة

---

## 🔍 شرح الكود

### 🗂️ لماذا حجزنا `int arr[102]` وليس `int arr[100]`؟

```cpp
int arr[102]; // وليس 100!
```

لأننا سنضيف **عنصرين إضافيين** لاحقاً، فيجب أن يكون الحجم أكبر بـ 2 على الأقل.  
إذا استخدمنا `arr[100]` وكان n=100 وأضفنا عنصرين سيحدث **تجاوز للذاكرة** وهذا خطأ!

---

### ➕ كيف نضيف عنصراً لنهاية المصفوفة؟

```cpp
arr[n]     = elem1; // نضعه في الموقع التالي مباشرة
arr[n + 1] = elem2; // والذي بعده
n = n + 2;          // نحدث الحجم
```

**مثال:**
```
قبل الإضافة: arr = [10, 20, 30]  →  n = 3
arr[3] = 40  →  [10, 20, 30, 40]
arr[4] = 50  →  [10, 20, 30, 40, 50]
n = 5
```

## 🖥️ مثال على الإخراج

```
======================================
   برنامج إضافة عناصر للمصفوفة
======================================
أدخل عدد العناصر الأولية: 3
أدخل 3 رقم:
  العنصر [1]: 10
  العنصر [2]: 20
  العنصر [3]: 30

--- المصفوفة قبل الإضافة ---
عدد العناصر: 3
[ 10, 20, 30 ]

--- إضافة عنصرين جديدين ---
أدخل العنصر الأول الجديد: 40
أدخل العنصر الثاني الجديد: 50

--- المصفوفة بعد الإضافة ---
عدد العناصر: 5
[ 10, 20, 30, 40, 50 ]

✅ تمت إضافة العنصرين بنجاح!
======================================
```

---

## 🧠 المفاهيم المستخدمة

| المفهوم | الشرح |
|---------|-------|
| `arr[n]` | الموقع التالي بعد آخر عنصر |
| `n = n + 2` | تحديث الحجم بعد الإضافة |
| `int arr[102]` | حجم أكبر لاستيعاب الإضافات |
