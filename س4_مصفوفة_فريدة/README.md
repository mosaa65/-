# 📘 السؤال الرابع - التحقق من فرادة عناصر المصفوفة 3×3

**اسم الطالب:** عمار الحميري  
**اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يأخذ مصفوفة ثنائية الأبعاد حجمها 3×3 ويتحقق: هل كل الأرقام فيها مختلفة أم يوجد رقم مكرر؟

---

## 🗂️ ما هي المصفوفة ثنائية الأبعاد؟

تخيلها كـ **جدول** فيه صفوف وأعمدة:

```
         عمود[0]  عمود[1]  عمود[2]
صف[0]  →    1        2        3
صف[1]  →    4        5        6
صف[2]  →    7        8        9
```

في C++ نكتبها:
```cpp
int matrix[3][3]; // 3 صفوف × 3 أعمدة = 9 خانة
```

للوصول لأي خانة: `matrix[رقم_الصف][رقم_العمود]`
```cpp
matrix[0][0] = 1; // الصف الأول، العمود الأول
matrix[1][2] = 6; // الصف الثاني، العمود الثالث
```

---

## 🔍 شرح الكود خطوة بخطوة

### 1️⃣ إدخال المصفوفة بحلقتين متداخلتين

```cpp
for (int i = 0; i < 3; i++) {       // حلقة الصفوف
    for (int j = 0; j < 3; j++) {   // حلقة الأعمدة
        cin >> matrix[i][j];
    }
}
```

حلقة داخل حلقة! الخارجية للصفوف، الداخلية للأعمدة.

---

### 2️⃣ تحويل المصفوفة لمصفوفة أحادية

```cpp
int flat[9]; // 3×3 = 9 عناصر
int k = 0;
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++)
        flat[k++] = matrix[i][j];
```

**المثال:** المصفوفة `[[1,2,3],[4,5,6],[7,8,9]]` تصبح `[1,2,3,4,5,6,7,8,9]`

هذا يُسهّل المقارنة!

---

### 3️⃣ مقارنة كل عنصر مع باقي العناصر

```cpp
for (int i = 0; i < 9; i++) {
    for (int j = i + 1; j < 9; j++) {
        if (flat[i] == flat[j]) {
            isUnique = false; // وجدنا تكراراً!
        }
    }
}
```

**لماذا `j = i + 1`؟** لتجنب مقارنة العنصر مع نفسه.

---

## 🖥️ مثال على الإخراج

**مثال 1 - كل الأرقام فريدة:**
```
أدخل المصفوفة:
matrix[0][0]: 1   matrix[0][1]: 2   matrix[0][2]: 3
matrix[1][0]: 4   matrix[1][1]: 5   matrix[1][2]: 6
matrix[2][0]: 7   matrix[2][1]: 8   matrix[2][2]: 9

✅ جميع العناصر فريدة - لا يوجد تكرار!
```

**مثال 2 - يوجد تكرار:**
```
أدخل المصفوفة:
matrix[0][0]: 1   matrix[0][1]: 2   matrix[0][2]: 3
matrix[1][0]: 4   matrix[1][1]: 2   matrix[1][2]: 6
...

⚠️  التكرار: الرقم 2 مكرر في المصفوفة!
❌ العناصر ليست فريدة - يوجد تكرار!
```

---

## 🧠 المفاهيم المستخدمة

| المفهوم | الشرح |
|---------|-------|
| `matrix[3][3]` | مصفوفة ثنائية الأبعاد |
| حلقتان متداخلتان | للمرور على الصفوف والأعمدة |
| `flat[]` | تحويل 2D إلى 1D لتسهيل المقارنة |
| `bool isUnique` | علم (flag) للنتيجة |
