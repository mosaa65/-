# 📘 السؤال التاسع - ترتيب الأرقام تصاعدياً وتنازلياً

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يطلب أرقاماً من المستخدم (حتى يدخل صفر للإيقاف)، ثم يطبعها:
- مرة **من الأصغر للأكبر** (تصاعدي)
- مرة **من الأكبر للأصغر** (تنازلي)

---

## 📚 مفهوم do-while (الحلقة الشرطية)

```cpp
do {
    cout << "أدخل رقم: ";
    cin >> input;
    if (input != 0) {
        arr[count] = input;
        count++;
    }
} while (input != 0);
```

**الفرق بين while و do-while:**
- `while` → يتحقق من الشرط **قبل** التنفيذ
- `do-while` → ينفذ **أولاً** ثم يتحقق

هنا نستخدم `do-while` لأننا نريد طلب إدخال واحد على الأقل قبل التحقق.

## 🔄 خوارزمية Bubble Sort (فقاعة الترتيب)

هذه الخوارزمية الأشهر لترتيب المصفوفات:

```cpp
void sortAscending(int arr[], int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // تبديل العنصرين
                int temp   = arr[j];
                arr[j]     = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

**كيف تعمل؟** تخيل فقاعات في الماء، الأكبر يطفو للأعلى:

```
المصفوفة: [5, 2, 8, 1]

الجولة 1:
  [5,2,8,1] → 5>2؟ نعم → [2,5,8,1]
  [2,5,8,1] → 5>8؟ لا
  [2,5,8,1] → 8>1؟ نعم → [2,5,1,8]  ← 8 وصل لمكانه ✅

الجولة 2:
  [2,5,1,8] → 2>5؟ لا
  [2,5,1,8] → 5>1؟ نعم → [2,1,5,8]  ← 5 وصل ✅

الجولة 3:
  [2,1,5,8] → 2>1؟ نعم → [1,2,5,8]  ← مرتب ✅

النتيجة: [1, 2, 5, 8]
```

## 🔄 الترتيب التنازلي

نفس الكود لكن نغير `>` إلى `<`:

```cpp
if (arr[j] < arr[j + 1]) { // الأصغر يطفو للأمام
    // تبديل
}
```

## 🧠 تبادل قيمتين (Swap)

```cpp
int temp   = arr[j];     // احفظ arr[j] مؤقتاً
arr[j]     = arr[j + 1]; // ضع arr[j+1] في مكان arr[j]
arr[j + 1] = temp;       // ضع المحفوظ في arr[j+1]
```

لماذا نحتاج `temp`؟ لو كتبنا مباشرة:
```cpp
arr[j] = arr[j+1]; // فقدنا قيمة arr[j] الأصلية!!
arr[j+1] = arr[j]; // هذا يساوي arr[j+1] = arr[j+1] ❌
```
