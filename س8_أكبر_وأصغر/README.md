# 📘 السؤال الثامن - إيجاد أكبر وأصغر رقم باستخدام دالة

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يستخدم **دالتين** منفصلتين لإيجاد أكبر وأصغر رقم في المصفوفة.

---

## 📚 ما هي الدالة (Function)؟

تخيل الدالة كـ **آلة** تأخذ مدخلات وتعطيك نتيجة.

```
            ┌─────────────┐
arr[], size → │   findMax   │ →  أكبر رقم
            └─────────────┘
```

في C++:
```cpp
int findMax(int arr[], int size) {
    // الكود...
    return maxVal; // إرجاع النتيجة
}
```

- `int` قبل الاسم = نوع القيمة التي ترجعها الدالة
- `int arr[]` = المصفوفة كمدخل
- `int size` = عدد العناصر
- `return` = أرجع هذه القيمة

---

## 🔍 شرح دالة findMax

```cpp
int findMax(int arr[], int size) {
    int maxVal = arr[0]; // افترض أن أول عنصر هو الأكبر
    for (int i = 1; i < size; i++) { // ابدأ من الثاني
        if (arr[i] > maxVal) {
            maxVal = arr[i]; // وجدت أكبر! حدّث
        }
    }
    return maxVal;
}
```

**تتبع المثال:** `[3, 7, 1, 9, 4]`
```
maxVal = 3  (نبدأ بالأول)
i=1: arr[1]=7 > 3 ✅  maxVal = 7
i=2: arr[2]=1 > 7 ❌
i=3: arr[3]=9 > 7 ✅  maxVal = 9
i=4: arr[4]=4 > 9 ❌
return 9 ✅
```

---

## 🔍 شرح دالة findMin

```cpp
int findMin(int arr[], int size) {
    int minVal = arr[0]; // افترض الأول هو الأصغر
    for (int i = 1; i < size; i++) {
        if (arr[i] < minVal) { // < وليس >
            minVal = arr[i];
        }
    }
    return minVal;
}
```

نفس الفكرة لكن بعلامة `<` بدل `>`.

---

## 📋 إعلان الدوال قبل main

```cpp
// إعلان مسبق (Declaration)
int findMax(int arr[], int size);
int findMin(int arr[], int size);

int main() {
    // ...
}

// التعريف الفعلي (Definition)
int findMax(...) { ... }
int findMin(...) { ... }
```

يجب إعلان الدالة **قبل** استخدامها، حتى لو تعريفها بعد main.

## 🧠 المفاهيم المستخدمة

| المفهوم | الشرح |
|---------|-------|
| `Function` | كتلة كود قابلة لإعادة الاستخدام |
| `return` | إرجاع قيمة من الدالة |
| `int arr[]` | تمرير مصفوفة للدالة |
| مبدأ الأكبر/الأصغر | نفترض أول عنصر ونقارن الباقين |
