# 📘 السؤال الثالث عشر - السجلات المتداخلة للكلية والطلاب

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

هذا البرنامج يبرمج نظاماً لإدخال بيانات الطلاب وحفظها. الجديد هنا أننا نستخدم:
1. `Struct` لتسجيل بيانات **الكلية**
2. `Struct` آخر لتسجيل بيانات **الطالب**، وداخله نستدعي بيانات الكلية! (مفهوم الـ Nesting)
3. نستخدم `Private` لحماية المتغيرات ولا نسمح بالوصول لها إلا عبر دوال `Public`.
4. التحقق من صحة الرقم الأكاديمي (لا يقل عن 6) والعمر (لا يقل عن 18).

---

## 📚 مفاهيم جديدة ومهمة!

### 1- ما هو الـ Nesting Struct (التداخل)؟

يعني وضع `Struct` كامل كـ **نوع بيانات** داخل `Struct` آخر!
تخيل أن الطالب لديه (اسم، وعمر) ولديه أيضاً (كلية). بدلاً من كتابة كل تفاصيل الكلية مع الطالب، ننشئ قالب الكلية وحده، ثم نضع منه نسخة داخل الطالب.

```cpp
struct College {
    string name;
    string university;
    // ...
};

struct Student {
    string name;
    int age;
    College college; // ⬅️ هنا التداخل! استدعينا الكلية داخل الطالب
};
```

### 2- ما هي Private و Public؟ (التغليف - Encapsulation)

في البرمجة القوية، لا يجب أن يتمكن أي شخص من تعديل المتغيرات مباشرة من دالة `main`!
- **`private:`** تعني هذه البيانات مخفية ومحمية، لا يمكن الوصول إليها إلا من داخل الـ `struct` نفسه.
- **`public:`** تعني هذه الدوال يمكن للجميع رؤيتها واستخدامها.

**لماذا؟** حتى نتمكن من مراقبة الإدخال. مثلاً لو وضعنا المتغير `age` كـ public، قد يكتب المستخدم `student.age = -5` وهذا خطأ!
أما بتغليفه ووضع الإدخال داخل دالة `public`، نستطيع وضع شرط (أكبر من 18) هناك.

```cpp
struct Student {
private:
    int age; // لا أحد يقدر يوصل له من برا

public:
    void input() { 
        // هنا نقدر نوصل له لأن الدالة داخل الـ struct
        cin >> age; 
    }
};
```

## 🔍 شرح بعض أجزاء الكود

### التحقق من طول الرقم الأكاديمي

```cpp
do {
    cout << "الرقم الأكاديمي (6 أرقام على الأقل): ";
    getline(cin, studentId);
} while (studentId.length() < 6);
```

دالة `.length()` تحسب عدد أحرف النص المدخل. إذا كان أقل من 6، نعيد الحلقة.

### إدخال بيانات الكلية من داخل الطالب

في دالة `inputStudentData`، وعندما نصل لدور الكلية:
```cpp
college.inputCollegeData(); 
```
تستدعي الدالة الخاصة بإدخال بيانات الكلية، فتظهر أسئلة الكلية تلقائياً!
