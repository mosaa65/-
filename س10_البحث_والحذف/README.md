# 📘 السؤال العاشر - البحث عن عنصر وحذفه من المصفوفة

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يبحث عن رقم في المصفوفة، وإذا وجده يحذفه ويعرض المصفوفة بعد الحذف.

---

## 🔍 شرح دالة البحث

```cpp
int searchElement(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return i;   // وجدناه! أعد موقعه
        }
    }
    return -1; // لم نجده → نعيد -1 كعلامة
}
```

**لماذا -1؟** لأن المواقع الحقيقية تبدأ من 0، فـ -1 تعني "غير موجود".

---

## 🗑️ شرح دالة الحذف (الفكرة الذكية!)

في C++ لا يمكن حذف عنصر من المصفوفة فعلياً. بدلاً من ذلك، **نزحزح ما بعده:**

```cpp
void removeElement(int arr[], int &size, int index) {
    for (int i = index; i < size - 1; i++) {
        arr[i] = arr[i + 1]; // اكتب فوق العنصر المحذوف
    }
    size--; // نقص الحجم
}
```

**مثال: حذف الرقم 8 من الموقع [2]**
```
قبل الحذف: [ 3, 5, 8, 2, 7 ]  size=5
                     ↑ index=2

الزحزحة:
arr[2] = arr[3] = 2  →  [ 3, 5, 2, 2, 7 ]
arr[3] = arr[4] = 7  →  [ 3, 5, 2, 7, 7 ]
size-- = 4

بعد الحذف: [ 3, 5, 2, 7 ]  size=4  ✅
```

---

## 📌 ملاحظة: `int &size`

```cpp
void removeElement(int arr[], int &size, int index)
//                                 ↑
//                          علامة & تعني "Reference"
```

`&` تعني: لا تعمل نسخة من المتغير، بل **عدّل الأصل مباشرة**.  
بدون `&` تتغير قيمة size داخل الدالة فقط ولا تؤثر على main!

```
--- المصفوفة بعد الحذف ---
[ 3, 5, 2, 7 ]
عدد العناصر: 4
```
