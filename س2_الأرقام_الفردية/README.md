# 📘 السؤال الثاني - استخراج الأرقام الفردية

**اسم الطالب:** عمار الحميري  
**اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يأخذ مصفوفة من الأرقام، يستخرج **الأرقام الفردية فقط** ويضعها في مصفوفة جديدة ثم يعرضها.

---

## 🤔 ما هو الرقم الفردي (Odd Number)؟

- الرقم الفردي هو الرقم **الذي لا يقبل القسمة على 2**
- مثال: 1، 3، 5، 7، 9، 11 ...
- الرقم الزوجي هو الذي **يقبل القسمة على 2**
- مثال: 2، 4، 6، 8، 10 ...

**كيف نعرف في البرمجة؟**

```cpp
if (arr[i] % 2 != 0)   // إذا الباقي من القسمة ≠ 0 → فردي
if (arr[i] % 2 == 0)   // إذا الباقي من القسمة = 0 → زوجي
```

رمز `%` يسمى **Modulo** ويعطينا باقي القسمة:
```
7 % 2 = 1  (لأن 7 = 2×3 + 1)  → فردي ✅
8 % 2 = 0  (لأن 8 = 2×4 + 0)  → زوجي ❌
```

## 🔍 شرح الكود خطوة بخطوة

### الخطوة 1️⃣ - إدخال المصفوفة

```cpp
int n;
cin >> n;

int arr[100];
for (int i = 0; i < n; i++) {
    cin >> arr[i];
}
```

نفس الطريقة دائماً: نطلب العدد، ثم نملأ المصفوفة بالحلقة.

---

### الخطوة 2️⃣ - استخراج الأرقام الفردية

```cpp
int oddArr[100]; // مصفوفة فارغة جديدة للأرقام الفردية
int oddCount = 0; // عداد يبدأ من صفر

for (int i = 0; i < n; i++) {
    if (arr[i] % 2 != 0) {   // إذا الرقم فردي
        oddArr[oddCount] = arr[i]; // أضفه للمصفوفة الجديدة
        oddCount++;           // زد العداد بواحد
    }
}
```

**تتبع المثال:**
```
المصفوفة الأصلية: [2, 5, 8, 3, 10, 7]

i=0 → arr[0]=2  → 2%2=0  → زوجي، تجاهل
i=1 → arr[1]=5  → 5%2=1  → فردي! ✅ oddArr[0]=5, oddCount=1
i=2 → arr[2]=8  → 8%2=0  → زوجي، تجاهل
i=3 → arr[3]=3  → 3%2=1  → فردي! ✅ oddArr[1]=3, oddCount=2
i=4 → arr[4]=10 → 10%2=0 → زوجي، تجاهل
i=5 → arr[5]=7  → 7%2=1  → فردي! ✅ oddArr[2]=7, oddCount=3

النتيجة: oddArr = [5, 3, 7]
```

---

### الخطوة 3️⃣ - عرض النتيجة مع التحقق

```cpp
if (oddCount == 0) {
    cout << "لا توجد أرقام فردية!" << endl;
} else {
    for (int i = 0; i < oddCount; i++) {
        cout << oddArr[i] << " ";
    }
}
```

نتحقق أولاً: هل يوجد أرقام فردية أصلاً؟ إذا لا، نطبع رسالة مناسبة.

## 🧠 الفكرة الجوهرية

نستخدم **مصفوفتين**:
1. `arr[]` → تخزن كل الأرقام
2. `oddArr[]` → تخزن الفرديين فقط

ومتغير `oddCount` يعمل كمؤشر وعداد في نفس الوقت.

| المفهوم | الاستخدام |
|---------|-----------|
| `%` (Modulo) | لمعرفة باقي القسمة |
| مصفوفة ثانية | لتخزين النتائج المفلترة |
| `oddCount` | عداد ومؤشر للمصفوفة الجديدة |
