# 📘 السؤال السابع - نفقات الفريق الرياضي

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يتتبع نفقات فريق رياضي على مدار العام باستخدام مصفوفة ثنائية الأبعاد:
- **الصفوف** = أنواع النفقات (إيجار، معدات، سفر)
- **الأعمدة** = الأشهر الـ 12

ثم يحسب مجموع كل نوع نفقة والمجموع الكلي.

---

## 🗂️ كيف تبدو المصفوفة؟

```
             يناير  فبراير  مارس  ...  ديسمبر   المجموع
الإيجار   →  5000   5000   5000  ...   5000    60,000
المعدات   →  2000   1500   3000  ...   2000    27,000
السفر     →   800   1200    400  ...    600    11,000

المجموع الكلي = 98,000 ريال
```

---

## 🔍 شرح حساب المجاميع

```cpp
double grandTotal = 0;

for (int e = 0; e < 3; e++) {      // لكل نوع نفقة
    double rowSum = 0;
    for (int m = 0; m < 12; m++) { // لكل شهر
        rowSum += expenses[e][m];  // جمع الشهر
    }
    grandTotal += rowSum;          // إضافة لمجموع الكلي
    cout << "مجموع " << expenseNames[e] << ": " << rowSum;
}
cout << "المجموع الكلي: " << grandTotal;
```

---

## 🧠 المفاهيم المستخدمة

| المفهوم | الشرح |
|---------|-------|
| `expenses[3][12]` | 3 أنواع نفقات × 12 شهر |
| `rowSum` | مجموع صف واحد (نوع نفقة واحد) |
| `grandTotal` | مجموع كل شيء |
| `string` arrays | لأسماء الأشهر وأنواع النفقات |
