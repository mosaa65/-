# 📘 السؤال الحادي عشر - معلومات المبيعات باستخدام Struct

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يستخدم `struct` لتخزين بيانات المندوبين (الاسم، الشهر، مبيعات 3 منتجات)، ثم يعرض جميع المندوبين، وفي النهاية يطلب رقمًا معينًا (الحد الأدنى) ويعرض فقط المندوبين الذين تجاوزت مبيعاتهم الكلية هذا الرقم.

---

## 📚 ما هو الـ Struct (السجل)؟

في العادة، المصفوفة `Array` تخزن نوعًا واحدًا من البيانات المتشابهة (مثلا كل العناصر `int`). لكن ماذا لو أردنا تخزين بيانات طالب (اسمه `string`، عمره `int`، درجته `double`)؟ هنا نستخدم الـ **Struct**.

الـ `struct` يجمع عدة متغيرات من أنواع مختلفة تحت اسم واحد.

```cpp
struct SalesRecord {
    string repName;
    string month;
    double product1;
    double product2;
    double product3;
    double totalSales;
};
```

---

## 🔍 كيف نستخدم Struct؟

**1. إنشاء متغير من نوع Struct:**
```cpp
SalesRecord rec;
```

**2. الوصول للعناصر باستخدام النقطة `. `:**
```cpp
rec.repName = "عمار";
rec.product1 = 150.5;
```

**3. إنشاء مصفوفة من السجلات (Array of Structs):**
```cpp
SalesRecord records[50];
records[0].repName = "عمار";
```

## 🔍 شرح بعض الدوال المهمة في البرنامج

### `cin.ignore()`
عند إدخال رقم (مثل `cin >> n`) ثم إدخال نص (مثل `getline`)، قد يتبقى حرف "Enter" في الذاكرة ويتسبب في تخطي إدخال النص الأول. `cin.ignore()` تتجاهل هذا الحرف.

### حساب الإجمالي
نقوم بحساب `totalSales` تلقائيًا بمجرد إدخال مبيعات المنتجات الثلاثة لنوفّر الوقت على المستخدم.
