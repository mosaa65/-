# 📘 السؤال السادس - متوسط درجات الحرارة الأسبوعية

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يخزن درجات الحرارة لكل يوم في كل أسبوع من الشهر (4 أسابيع × 7 أيام = 28 يوم)،  
ثم يحسب **متوسط درجة الحرارة** لكل أسبوع.

---

## 🗂️ كيف تبدو المصفوفة؟

```
              الأحد   الاثنين   الثلاثاء  ...  السبت
الأسبوع 1  →   25      27        26    ...    22
الأسبوع 2  →   30      28        31    ...    29
الأسبوع 3  →   24      25        23    ...    26
الأسبوع 4  →   20      19        22    ...    21
```

في الكود: `temp[أسبوع][يوم]`

---

## 🔍 شرح حساب المتوسط

```cpp
double sum = 0;
for (int d = 0; d < 7; d++) {
    sum += temp[w][d];   // جمع كل أيام الأسبوع
}
double average = sum / 7; // القسمة على 7 أيام
```

**مثال:**
```
أيام الأسبوع 1: 25, 27, 26, 28, 30, 24, 22
المجموع = 25+27+26+28+30+24+22 = 182
المتوسط = 182 ÷ 7 = 26.0 درجة
```

---

## 🧠 المفاهيم المستخدمة

| المفهوم | الشرح |
|---------|-------|
| `double temp[4][7]` | مصفوفة ثنائية لدرجات الحرارة |
| `string dayNames[7]` | مصفوفة من النصوص لأسماء الأيام |
| `sum / DAYS` | حساب المتوسط الحسابي |
| حلقتان متداخلتان | للمرور على الأسابيع والأيام |
