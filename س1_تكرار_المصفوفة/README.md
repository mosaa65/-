# 📘 السؤال الأول - حساب تكرار الأرقام في المصفوفة

**اسم الطالب:** عمار الحميري  
**المادة:** البرمجة  
**اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

البرنامج هذا يطلب منك أن تدخل مجموعة من الأرقام، ثم يحسب **كم مرة تكرر كل رقم** في المصفوفة ويعرض النتيجة.

---

## 📚 المصطلحات الأساسية (للمبتدئين تماماً)

### ما هي المصفوفة (Array)؟
تخيل عندك **صف من الصناديق**، كل صندوق يحمل رقم واحد.

```
صندوق[0]  صندوق[1]  صندوق[2]  صندوق[3]  صندوق[4]
   5          3          5          7          3
```

هذا يسمى **مصفوفة** وفي C++ نكتبها هكذا:
```cpp
int arr[100]; // مصفوفة تتسع لـ 100 رقم
```

## 🔍 شرح الكود خطوة بخطوة

### الخطوة 1️⃣ - تضمين المكتبات

```cpp
#include <iostream>
using namespace std;
```

- `#include <iostream>` → هذا يجلب أدوات الإدخال والإخراج (مثل cout و cin)
- `using namespace std;` → يوفّر علينا كتابة `std::` قبل كل أمر

---

### الخطوة 2️⃣ - الدالة الرئيسية main

```cpp
int main() {
    // الكود هنا
    return 0;
}
```

كل برنامج C++ يبدأ من `main()` - هي نقطة الانطلاق دائماً.

---

### الخطوة 3️⃣ - طلب عدد العناصر

```cpp
int n;
cout << "أدخل عدد العناصر: ";
cin >> n;
```

- `int n;` → أنشأنا **متغير** اسمه n يحفظ رقم
- `cout` → يعني "اطبع على الشاشة"
- `cin >> n` → يعني "اقرأ ما يكتبه المستخدم وخزّنه في n"

**مثال:** لو كتب المستخدم 5، إذن n = 5

---

### الخطوة 4️⃣ - إدخال العناصر بحلقة for

```cpp
int arr[100];
for (int i = 0; i < n; i++) {
    cout << "العنصر [" << i + 1 << "]: ";
    cin >> arr[i];
}
```

**حلقة for** تعني: "كرّر هذا الكود عدة مرات"

```
i = 0 → اطلب أول رقم وخزّنه في arr[0]
i = 1 → اطلب ثاني رقم وخزّنه في arr[1]
i = 2 → اطلب ثالث رقم وخزّنه في arr[2]
... وهكذا حتى i = n-1
```

---

### الخطوة 5️⃣ - حساب التكرار (القلب الأساسي للبرنامج)

```cpp
bool alreadyCounted[100] = {false};

for (int i = 0; i < n; i++) {
    if (!alreadyCounted[i]) {
        int count = 1;
        for (int j = i + 1; j < n; j++) {
            if (arr[i] == arr[j]) {
                count++;
                alreadyCounted[j] = true;
            }
        }
        alreadyCounted[i] = true;
        cout << arr[i] << " تكرر: " << count << " مرة" << endl;
    }
}
```

**الفكرة الذكية هنا:**
- نستخدم مصفوفة `alreadyCounted` للتتبع
- `bool` يعني قيمة منطقية: إما `true` (صح) أو `false` (خطأ)
- لكل عنصر، نبحث عن نفسه في بقية المصفوفة ونعدّ كم مرة ظهر

**مثال تفصيلي:**

```
المصفوفة: [5, 3, 5, 7, 3]

i=0 → arr[0]=5، لم يُحسب بعد
    j=1 → arr[1]=3 ≠ 5
    j=2 → arr[2]=5 = 5 ✅ count=2، alreadyCounted[2]=true
    j=3 → arr[3]=7 ≠ 5
    j=4 → arr[4]=3 ≠ 5
    → اطبع: "5 تكرر 2 مرة"

i=1 → arr[1]=3، لم يُحسب بعد
    j=2 → alreadyCounted[2]=true، تخطاه
    j=3 → arr[3]=7 ≠ 3
    j=4 → arr[4]=3 = 3 ✅ count=2
    → اطبع: "3 تكرر 2 مرة"

i=2 → alreadyCounted[2]=true، تخطاه ✋

i=3 → arr[3]=7، لم يُحسب
    → count=1 (لا يوجد آخر مثله)
    → اطبع: "7 تكرر 1 مرة"

i=4 → alreadyCounted[4]=true، تخطاه ✋
```

## 🧠 ملخص المفاهيم المستخدمة

| المفهوم | الاستخدام |
|---------|-----------|
| `int arr[100]` | مصفوفة لتخزين الأرقام |
| `for` loop | تكرار الأوامر |
| `if` statement | شرط للتحقق |
| `bool` | قيمة صح أو خطأ |
| `cout` | طباعة على الشاشة |
| `cin` | قراءة إدخال المستخدم |
