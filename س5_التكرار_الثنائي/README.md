# 📘 السؤال الخامس - إيجاد الأرقام المكررة في المصفوفة 4×4

**اسم الطالب:** عمار الحميري | **اللغة:** C++

---

## 🎯 ماذا يفعل البرنامج؟

يأخذ مصفوفة 4×4 ويطبع فقط الأرقام التي **تكررت أكثر من مرة واحدة**.

---

## 🔍 الفرق بين السؤال 4 والسؤال 5

| السؤال 4 | السؤال 5 |
|----------|----------|
| 3×3 | 4×4 |
| يقول هل يوجد تكرار؟ نعم/لا | يعرض **أي** الأرقام تكررت |

---

## 🔍 شرح الكود

### الفكرة الأساسية

```cpp
bool printed[16] = {false}; // لتجنب طباعة الرقم مرتين

for (int i = 0; i < 16; i++) {
    if (printed[i]) continue; // تجاوز، سبق حسابه

    int count = 1;
    for (int j = i + 1; j < 16; j++) {
        if (flat[i] == flat[j]) {
            count++;
            printed[j] = true;
        }
    }

    if (count > 1) { // إذا تكرر أكثر من مرة
        cout << "الرقم " << flat[i] << " تكرر " << count << " مرات";
    }
}
```
